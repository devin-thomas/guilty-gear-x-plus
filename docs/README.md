# Playing Guilty Gear X Plus on Windows and Mac

These pages are for players. The port runs the PlayStation 2 game's own code
natively on Windows 10 and 11 (64-bit) and macOS 14 or later (Apple
Silicon), frame for frame as the PS2 runs it in PCSX2. It ships no game data: you bring your
own copy of the disc, and the port reads it once.

2. [Your disc](disc.md): which discs work, making an image, the first run

## In short

- Supported discs: **Guilty Gear X Plus (Korea), SLPM-645.25** and
  **Guilty Gear X Plus (Japan), SLPS-201.37**, as an ISO, BIN/CUE or CHD
  image of your own disc.
- On the first launch the game asks for the image, checks it and copies
  its files. After that it starts straight into the game.
- **X confirms in menus** and Circle goes back (the PS2 releases did it the
  other way round; one setting restores that).
- **F9** (or Select held for a second) opens the port's settings.
  **F2** switches between the original text and English.
- Fights you finish are saved as replays; your saves are in the port's own
  folder and can be exported to a PCSX2 memory card.
